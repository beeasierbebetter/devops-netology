# Домашнее задание к занятию «Системы контроля версий» `Котуков Евгений`

В .gitignore внутри директории terraform будут скрыты все скрытые конфигурационные локальные файлы самого terraform (включая влоэженные в директорию файлы и поддиректории), \
файлы с текущим состоянием проекта (tfstate) - где все id и характеристики реально работающих сущностей проекта, \
логи о падении terraform, файлы с переменными (tfvars), локальные оверрайды параметров проекта, \
файл блокировки, создаваемый после terraform apply, а так же параметры командной утилиты terraform cli
